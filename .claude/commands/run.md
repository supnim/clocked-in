# Build and Run

Build and launch Clocked-In in the simulator.

## Instructions

1. Use XcodeBuildMCP build and run tools:
   - `mcp__xcodebuildmcp__build_run_sim_name_proj`

2. The app will launch in the macOS simulator or directly if on macOS

3. Watch for:
   - Console output for errors
   - Firebase connection issues
   - Permission prompts

## Usage

```
/project:run             # Build and run in simulator
```

## Notes

- The app runs as a menu bar / notch app
- Look for the status item in the menu bar
- Hover over the notch area to expand the UI
- Check Console.app for detailed logs
